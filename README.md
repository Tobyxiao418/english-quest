# English Quest · 英语开口小冒险

面向能读简单英语、还不太敢开口的高年级小学生。零新增付费的电脑网页试用版。

## 使用
打开网站，选择生活任务，按听音理解 → 拼句/听写 → 跟读录音回听 → 自己表达的流程练习。建议完成三个主题，中途可休息。30–45分钟是练习路线的设计预估，实际时长取决于孩子；不以强制等待凑时长。

- 推荐更新的 Chrome / Edge，允许网页播放声音。
- 首次录音由用户点击后请求麦克风权限。录音只存在当前页面内存，不上传，不长期保存；换题会清理。
- 语音示范使用浏览器英语语音。设备需有可用英语声音；不同系统效果不同。
- 首版**没有AI口语评分、没有云端语音识别、没有自然AI聊天**。录音回听和自我检查用于鼓励开口，完成标记不代表已经掌握。
- 进度只保存在当前浏览器，可导出摘要。清理网站数据、更换浏览器可能失去原进度。
- 网站公开可访问，不是家庭登录服务。没有孩子姓名、学校、个人录音或学习记录存放在GitHub。
- 网站托管平台仍可能处理普通访问日志；“不上传学习记录”不代表互联网请求没有技术日志。

## 内容
原创生活情景：放学后的兴趣、在小店购物、周末计划。参考小学基础表达难度，不宣称已匹配湖南某个教材版本。每课18个步骤，三课54步，口语练习与听读写交替。

## 开发
Node.js 20+。无生产第三方依赖。

```sh
npm test
python3 -m http.server 8765 --bind 127.0.0.1
```

在本机浏览器打开 http://127.0.0.1:8765 。部署须HTTPS，麦克风需要安全上下文。

## 开源调研与范围取舍
查阅了 [Earthworm](https://github.com/cuixueshe/earthworm)（AGPL-3.0）和 [Qwerty Learner](https://github.com/RealKai42/qwerty-learner)（GPL-3.0）。前者渐进构句方法贴近需求，但整套运行依赖Postgres、Redis、Docker及用户系统；后者成熟但主要面向单词输入训练。

本项目借鉴“词组到句子、输入到回忆”的练习思路，**未复制这两个项目的源代码、词库或品牌资产，不宣称是其分支或官方版本**。选择独立轻量实现，是为了避免免费静态发布引入后端维护成本。

## 迭代顺序
先收集孩子真实试用反馈：敢不敢开口、哪里卡住、难度是否合适。再考虑复习调度、更多题材、经过验证的免费语音识别。未经家长确认，不启用新付费服务或音频上传。
